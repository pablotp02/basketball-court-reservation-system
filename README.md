# Basketball Court Reservation System

Web-based reservation system developed as part of a group academic project for the Web Programming course.

## Overview

This project implements a management system for basketball court reservations, including user authentication, reservation handling, material management, and administrative functionality.

The system supports different user roles (administrators and clients) and applies business logic such as discounts and reservation constraints.

## Features

- User registration and authentication
- Basketball court availability management
- Reservation creation, modification, and cancellation
- Material association with courts
- Administrative panel for system management
- Role-based access control

## Technologies Used

- Java (Servlets)
- JSP
- HTML / CSS
- Relational Database (SQL)
- Apache Tomcat

## Project Context

This repository contains the final version of a project developed incrementally across three academic assignments during the Bachelor's Degree in Computer Engineering.
